Below are examples of three techniques used to compress raster images.

Indexed color uses a palette generated via the "median-cut" method: repeatedly find the channel with the highest range and split into buckets until the desired amount of colors is reached. It may lag above 512 colors due to the overhead with Javascript. At and above this threshold, the amount of colors allows for the gradient to be visibly apparent, however the light source and shapes with primary colors are not properly represented until 2048 or more colors. This could be remedied with a method that determines palette colors via a perceptive method instead of a simple median-cut. Because 24-bit color allows for 16,777,216 possible colors, using a palette greatly reduces the size of many images in return for the loss of gradient information.

Color Quantization works per-channel, and simply snaps the values of each channel to a desired number of levels. For the most part, this technique can reduce color accuracy in a way that is generally imperceptible and saves a significant amount of space (25% or more). The first visual issue to appear is color banding on gradients, which will be present for this type of compression.

The Block Average implementation here allows for mismatched block sizes, but does not account for it. Any non-existent pixels are simply excluded, yet the full block size is expected for the final color information, leading to darkened edges on the bottom and right. Preferably, I would have liked to implement padding, but I believe that is outside the scope of this assignment.
